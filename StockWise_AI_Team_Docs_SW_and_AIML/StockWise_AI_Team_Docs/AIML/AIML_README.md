# AI/ML Team README

## Mission
Provide validated forecasts and feasible distribution decisions through tested reusable Python modules and stable contracts.

- **ML1 Data/Forecasting:** data profile, preprocessing, baseline/candidate model, chronological backtests, metrics, model versioning and monitoring.
- **ML2 Optimization:** risk rules, replenishment, constrained allocation, expiry-aware rules, independent feasibility validation, baseline comparison and explanations.

Deliver reusable modules (not only notebooks), typed inputs/outputs, fixtures, model/evaluation metadata, integration guide and limitations. Never claim accuracy without backtests. Never silently violate constraints. Separate forecast estimates, proposals and actual outcomes.
