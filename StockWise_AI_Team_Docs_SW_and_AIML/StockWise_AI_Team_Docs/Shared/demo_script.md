# Demo Script (5–7 minutes)

## Before demo
Reset DB, run migrations/seed, verify frontend/backend/DB, use labeled synthetic data, test seeded shortage and surplus/expiry case, verify all charts come from real API data, and identify simulated/disabled integrations.

1. **Problem (30s):** StockWise helps distribution teams decide what to replenish, where stock should move and which expiry risks need action.
2. **Data (45s):** Upload CSV; show mapping, validation, row counts and freshness.
3. **Predict (60s):** Show forecast horizon, baseline/model label and risk.
4. **Optimize (90s):** Generate allocation; explain only constraints actually implemented; show baseline comparison and feasibility.
5. **Approve (60s):** Inspect inputs/assumptions, approve/reject, verify persisted state and audit.
6. **Measure (45s):** Show evaluation/outcome metrics only if calculated from test/actual data. Clarify internal record versus real external execution.
7. **Close (20s):** “Validated data, demand prediction, constrained allocation, explainable recommendations, safe approval and measurable follow-up.”

Never claim real supplier orders, prevented waste, accuracy or savings without evidence. If something fails, state the limitation honestly.
